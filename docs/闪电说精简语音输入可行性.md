# 闪电说精简语音输入可行性调研

调研日期：2026-10-12。对象：本机 /Applications/闪电说.app，版本 0.8.0，arm64。

## 结论

开发个人使用的 macOS 精简语音输入工具可行。推荐菜单栏小工具：全局快捷键 → 录音及流式语音识别 → 可选轻度纠错 → 自动粘贴到当前输入框。第一版采用自有服务商 API Key，不依赖闪电说内部会员协议。

“调用与闪电说相同的语音服务商”与“使用闪电说会员额度”是两件事。前者有官方 API 接入路径；后者尚未确认开放或获准。

## 精简实现建议（设计建议，非逆向还原）

平台暂按当前使用环境 macOS。采用 Swift + AppKit/SwiftUI、AVAudioEngine，配置页只保留快捷键、麦克风、语音识别服务和 API Key。凭证放 Keychain。

第一版保留：快捷键开始/结束、录音状态提示、一个流式 ASR 适配、取消与失败重试、自动粘贴、粘贴失败后的复制回退。先不增加读屏、Agent、知识库、长期记忆或多模型编排。

常规使用的语音输入体验不必从系统 InputMethodKit 输入法开始；菜单栏工具即可验证核心需求。全局快捷键和模拟粘贴需要按实现方式处理系统权限。自动输入以受控剪贴板粘贴为主，保留原剪贴板并避免覆盖用户在过程中复制的新内容，处理焦点变化和目标 App 差异。

低延迟重点是边说边上传、及时提交结束标记、等待最终结果时避免额外模型调用。首版可直接输出 ASR 结果；确有需要时再加入可关闭的轻度纠错。语言大模型不等于语音识别模型，普通文本聊天 API 不能直接承担音频转写。

经验工作量估算（非承诺）：熟悉 macOS 开发且已有有效 API Key 的情况下，基本原型约 1–3 天；个人日用版约 1–2 周；录音设备切换、蓝牙、休眠恢复、异常网络和多应用兼容完善可能需要 2–4 周或更久。精确时延和费用需按选定服务商及实际录音测试。

## 闪电说会员能否复用

技术层面：发现会员 ASR 适配模块，表明应用存在会员服务接入逻辑。独立客户端是否能调用，仍取决于真实协议、会话刷新、服务端约束和厂商许可。没有进行会员凭证读取、请求重放或接口调用测试。

公开支持层面：此次查看官网入门、模型、定价与服务条款页面，未找到向第三方客户端开放的会员 API 或开发者密钥说明。这是限定范围内的未发现，不代表厂商绝对不提供。

条款层面：当前公开服务条款（标注最后修改于 2025-11-15）明确禁止反向工程、反编译、破解等获取源代码的行为，并限制未经许可复制修改软件。这是对页面内容的转述，不判断具体法律效力。购买年费不能据此推导出自建客户端调用授权。
来源：https://shandianshuo.cn/terms

可向官方询问的准确问题：我有年费会员，能否在自用 macOS 客户端调用语音识别与轻度纠错接口，并计入现有会员额度？是否提供官方 API、SDK、独立密钥或本地自动化接口？

建议先把核心工具和服务商适配接口做独立，使用自己的官方 API；若官方允许会员接入，之后再增加闪电说适配器。
