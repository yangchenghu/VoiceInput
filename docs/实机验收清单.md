# 实机验收清单

单元测试不能代替下面这些。每一项标上通过、失败或未测。

## 核心场景

1. 复制一个网址，切到 Cursor，按住右 Command 说话，松开后出现文字；接着 Command+V 仍是原来的网址。
2. 默认模式下，剪贴板内容和 changeCount 都不因这次语音输入改变。
3. 录音期间再复制另一个网址，语音输入结束后粘贴的是新网址。
4. 右 Command+C / V / Tab 正常，不冒出语音文字。左 Command 不开始录音。
5. 按住模式和点击切换模式都能开始、结束、取消。
6. 自定义快捷键保存后生效，重启后还在，恢复默认有效。
7. 胶囊出现在当前屏幕底部，不抢走 Cursor 的焦点。录音有时长，转写和纠错没有假进度。
8. 关闭纠错时只调用语音识别。打开后意思不变；把纠错地址填错或断网时，仍输入原来的转写。
9. 转写过程中按 Esc，之后才到的网络结果不会输入。
10. 语音输入不会自动按回车发送。
11. 录音开始后切到另一个应用，文字不会进那个新应用。
12. 失败时能看到原因。有录音缓存时可以重试，否则提示重新说。

## 边界

- 拒绝或撤销麦克风、辅助功能、输入监控。
- 凭证错误、额度不足、断网、WebSocket 中途断开、结果超时。
- 连续多次、极短、静音、接近 60 秒、快速连按。
- 中英混排、emoji、网址、代码、多行、选区替换。
- 蓝牙耳机切换、麦克风断开、睡眠唤醒。
- 多屏、全屏、不同缩放、输入时切换 Space。
- 安全输入框写不进去时有说明，不绕过系统限制。
- 兼容粘贴模式：纯文本、网址、图片、多种类型，以及粘贴过程中又复制了新内容。记下无法保证恢复的情况。
